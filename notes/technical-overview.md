This repo visualizes the relationships between Supreme Court justices using a graph. It pulls data from various sources to create an interactive representation of justices' connections over time. 

### Key Components
- **D3.js** for dynamic, interactive visualizations.
- **Node.js** as the backend to handle data retrieval.
- **React** for the frontend interface.

### Running the Project
To get this up and running quickly, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/justin-napolitano/sup-court-graph
   ```
2. Navigate to the project directory:
   ```bash
   cd sup-court-graph
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

### Gotchas
- Ensure you have Node.js installed. 
- Some visual aspects depend on your browser settings. Test in Chrome for best results.
